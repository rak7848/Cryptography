The Cryptography project executes two phases where students establish classical encryption basics and improve their functionality. 
The encryption project includes two phases which develop a hybrid encryption approach during Phase 1 and perform cryptanalysis to strengthen security during Phase 2.

Phase 1: Hybrid Encryption System

Students create Phase 1 encryption through a dual security mechanism that joins Monoalphabetic Substitution Cipher with the Caesar Cipher. The project involves:

The process of message encryption takes place through substitution together with shifting encryption methods which also handle the decryption process.

The program logs every transformation step through display interfaces to show system processes to users.

A portion of the application manages the workflow of plaintext documents and encryption output along with decrypted texts.

When users encrypt messages the system includes tests that ensure encryption stays accurate and safe.


Phase 2: Cryptanalysis and Improvements

In phase 2 the researchers apply cryptanalysis techniques to the cipher system through frequency analysis for decryption purposes. Key tasks include:

The process of breaking the cipher uses letter frequency analysis alongside diagram frequency analysis.

Students who successfully finish the two parts will gain thorough comprehension of traditional encryption methods together with cryptanalysis strategies as well as enhanced encryption protocol development for improved security.
